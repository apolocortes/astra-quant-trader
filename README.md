# Astra Quant Trader 🚀
Sistema institucional de análise quantitativa e gerenciamento de risco de alta frequência para Day Trade (focado em bater a meta diária de R$ 20 a R$ 30 por dia).

- **Engine:** GPT-6 Astra (192M tokens)
- **Framework:** Next.js 14 + TailwindCSS
- **Deploy:** Vercel Production
